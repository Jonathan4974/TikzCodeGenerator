From the feasible mass set to a primal certificate. Left: the first stage minimizes the quadratic objective $q(\mu)$ over the convex feasible mass set $\mathcal M(s)$. At an exact minimizer, the gradient $r=\mu^{\star}/w$ defines a supporting hyperplane of $\mathcal M(s)$, so the same normal vector makes $\mu^\star$ optimal for the linearized mass problem. This is still only mass-side information. Right: to recover a vertex potential, we solve the equivalent linear-cost min-cost-flow problem on the same lifted graph $G^\uparrow$; its dual node potential restricted to the original vertex set yields the support maximizer and hence the recovered primal potential.
